Bash là shell đăng nhập mặc định trên hầu hết hệ thống Linux, và vẫn là lựa chọn dễ chuyển đổi nhất cho script. Tuy nhiên, với công việc tương tác, Zsh (Z Shell) bổ sung những tính năng mà Bash không có mặc định: gợi ý dựa trên lịch sử, tô sáng cú pháp, và một prompt có thể hiển thị trạng thái Git cùng những ngữ cảnh khác.

Hướng dẫn này trình bày cách cài Zsh bằng Pixi, không cần quyền quản trị, rồi cấu hình Oh My Zsh, một vài plugin và một theme. Cùng một thiết lập dùng được trên Linux, macOS, WSL và các cụm HPC, và cấu hình có thể giữ trong một kho dotfiles.

<!--truncate-->

Sau khi hoàn tất thiết lập này, terminal sẽ có:

- **Cài đặt không cần quyền quản trị:** dùng được trên hệ thống không có `sudo`, kể cả cụm HPC
- **Nhận biết Git:** nhánh hiện tại và trạng thái hiện ra trong prompt
- **Gợi ý:** hoàn thiện dựa trên lịch sử và kiểm tra trực tiếp khi gõ lệnh

## 1. Vì sao dùng Zsh cho công việc tương tác?

Zsh là một shell được thiết kế cho công việc tương tác, mở rộng Bash với:

- **Hoàn thiện bằng Tab** - gợi ý theo ngữ cảnh cho lệnh, tệp và tham số
- **Sửa lỗi chính tả** - gợi ý sửa lỗi gõ
- **Hệ sinh thái plugin** - plugin cho Git, Docker, Python và hơn nữa
- **Theme** - prompt tuỳ biến với trạng thái Git và thông tin hệ thống
- **Lịch sử cải thiện** - lịch sử chia sẻ giữa các phiên và tìm kiếm tốt hơn
- **Globbing nâng cao** - mẫu đệ quy như `**/*.txt`

Với công việc terminal tương tác hàng ngày, Zsh là một nâng cấp hợp lý. Với script, Bash vẫn là lựa chọn dễ chuyển đổi hơn, vì nó gần như luôn có sẵn theo mặc định.

## 2. Cài đặt: Zsh với Pixi (không cần quyền quản trị)

Pixi `global install` có thể cài Zsh mà không cần `sudo` hay quyền quản trị. Cách này dùng được trên Linux, macOS, WSL và các cụm HPC.

### 2.1. Điều kiện tiên quyết

Trước khi cài Zsh bằng Pixi:

1. **Đã cài Pixi** - xem [Pixi, trình quản lý gói dựa trên conda](/blogs/pixi-is-new-conda-based-era) để thiết lập
2. **Không cần quyền admin hay sudo**

**Xác nhận Pixi đã sẵn sàng:**
```bash
pixi --version
# Should output: pixi X.X.X
```

### 2.2. Cài Zsh toàn cục bằng Pixi

Cài đặt chỉ là một lệnh:

```bash
# Install Zsh globally from conda-forge
pixi global install zsh --channel conda-forge
```

### 2.3. Nạp lại terminal và dùng Zsh

Sau khi cài, mở một terminal mới hoặc nạp lại terminal hiện tại:

```bash
# Option 1: Open a new terminal window
# Close current terminal and open a new one

# Option 2: Reload current terminal
exec bash

# Then verify Zsh is available
zsh --version

# Check where it's installed
which zsh
# Output: $HOME/.pixi/bin/zsh

# Launch Zsh
zsh
```

Pixi tự động thêm `~/.pixi/bin` vào `PATH` trong các terminal mới.

### 2.4. Cập nhật hoặc cài lại Zsh

```bash
# Update Zsh to latest version
pixi global upgrade zsh

# Reinstall with specific version
pixi global install zsh==5.9 --channel conda-forge --force

# List all globally installed packages
pixi global list

# Check Zsh version
zsh --version
```

### 2.5. Vì sao dùng `pixi global install` cho Zsh?

- **Cài bằng một dòng** - không cần dự án
- **Không cần quyền admin hay sudo** - cài vào thư mục home của người dùng
- **Tự động có sẵn** - chỉ cần nạp lại terminal, không cần export `PATH`
- **Tái lập được** - cùng phiên bản Zsh giữa các máy
- **Tách biệt** - không ảnh hưởng tới Zsh của hệ thống
- **Thân thiện với HPC** - chạy được trên cụm bị hạn chế
- **Cập nhật dễ** - `pixi global upgrade`
- **Kênh conda-forge** - một nguồn gói được bảo trì tốt

## 3. Oh My Zsh

Khi Zsh đã được cài qua Pixi, Oh My Zsh có thể quản lý plugin và theme.

### 3.1. Oh My Zsh là gì?

[**Oh My Zsh**](https://ohmyz.sh/) là một framework mã nguồn mở để quản lý cấu hình Zsh. Nó cung cấp:

- một bộ sưu tập plugin lớn (Git, Docker, Python, Node, kubectl và nhiều thứ khác)
- một bộ sưu tập theme lớn
- hệ thống tự cập nhật
- cấu hình qua một tệp `.zshrc` duy nhất

Lợi ích chính là tránh phải viết cấu hình Zsh phức tạp từ đầu và có sẵn plugin, theme do cộng đồng bảo trì, hoạt động trên Linux, macOS và WSL.

### 3.2. Cài Oh My Zsh

```bash
# Install via curl
sh -c "$(curl -fsSL https://raw.githubusercontent.com/ohmyzsh/ohmyzsh/master/tools/install.sh)"

# Or via wget
sh -c "$(wget -O- https://raw.githubusercontent.com/ohmyzsh/ohmyzsh/master/tools/install.sh)"
```

Điều gì xảy ra:

1. tạo thư mục `~/.oh-my-zsh/`
2. sao lưu `~/.zshrc` hiện có thành `~/.zshrc.pre-oh-my-zsh`
3. tạo một `~/.zshrc` mới với cấu hình Oh My Zsh mặc định
4. đặt Zsh làm shell mặc định (nếu chưa phải)

**Kiểm tra cài đặt:**
```bash
# Open a new terminal (or run)
exec zsh

# You should see a colorful prompt with Oh My Zsh
```

### 3.3. Tệp `.zshrc`

Tệp `~/.zshrc` là tệp cấu hình của Zsh, tương tự `.bashrc` với Bash:

```bash
# Open in your favorite editor
nano ~/.zshrc
# or
vim ~/.zshrc
# or
code ~/.zshrc  # VS Code
```

**Các phần chính trong `.zshrc`:**
```bash
# Path to Oh My Zsh installation
export ZSH="$HOME/.oh-my-zsh"

# Theme configuration
ZSH_THEME="robbyrussell"

# Plugins to load
plugins=(git)

# Load Oh My Zsh
source $ZSH/oh-my-zsh.sh

# Your custom aliases and functions go below
```

**Áp dụng thay đổi:**
```bash
# After editing .zshrc, reload configuration
source ~/.zshrc
```

## 4. Plugin

### 4.1. Plugin có sẵn

Oh My Zsh bao gồm nhiều plugin. Có thể bật plugin Git và Docker trong `~/.zshrc`:

```bash
plugins=(
  git              # Git aliases: gst, ga ., gcmsg, gp, gl, glol
  docker           # Docker aliases: dps, di, dstop
)
```

**Nạp lại:**
```bash
source ~/.zshrc
```

### 4.2. Plugin bên ngoài

Hai plugin bên ngoài thường được thêm vào:

#### 1. **zsh-autosuggestions** - hoàn thiện dựa trên lịch sử

Hiển thị gợi ý từ lịch sử khi gõ (màu xám). Nhấn mũi tên phải để chấp nhận.

```bash
git clone https://github.com/zsh-users/zsh-autosuggestions ${ZSH_CUSTOM:-~/.oh-my-zsh/custom}/plugins/zsh-autosuggestions

# Add to ~/.zshrc plugins
plugins=(... zsh-autosuggestions)
source ~/.zshrc
```

**Cách dùng:**
```bash
# Type a previous command prefix
git c<press right arrow>  # Auto-completes: git commit

# Cycle through suggestions
git <press up/down>  # Cycle through previous 'git' commands
```

#### 2. **zsh-syntax-highlighting** - kiểm tra trực tiếp

Tô sáng lệnh khi gõ: xanh cho hợp lệ, đỏ cho không hợp lệ.

```bash
git clone https://github.com/zsh-users/zsh-syntax-highlighting.git ${ZSH_CUSTOM:-~/.oh-my-zsh/custom}/plugins/zsh-syntax-highlighting

# Add to ~/.zshrc plugins (must be LAST)
plugins=(... zsh-syntax-highlighting)
source ~/.zshrc
```

Điều này giúp phát hiện lỗi gõ trước khi nhấn Enter.

### 4.3. Thiết lập plugin đầy đủ

```bash
# Edit ~/.zshrc
plugins=(
  git
  docker
  zsh-autosuggestions
  zsh-syntax-highlighting
)

source ~/.zshrc
```

## 5. Theme

### 5.1. Powerlevel10k

[**Powerlevel10k**](https://github.com/romkatv/powerlevel10k) là một theme Zsh phổ biến với trạng thái Git, phiên bản Python và một wizard cấu hình tương tác.

```bash
# Install
git clone --depth=1 https://github.com/romkatv/powerlevel10k.git ${ZSH_CUSTOM:-$HOME/.oh-my-zsh/custom}/themes/powerlevel10k

# Set in ~/.zshrc
ZSH_THEME="powerlevel10k/powerlevel10k"

# Reload - configuration wizard will launch
source ~/.zshrc
```

**Prompt có thể hiển thị:**
```bash
┌──(user@hostname)-[~/my-repo]-[main ✓]-[🐍 3.11.4]
└─$ 
```

- `main ✓` - nhánh Git cùng trạng thái của nó
- `🐍 3.11.4` - phiên bản Python đang dùng
- Biểu tượng Git: `✓` (sạch), `!` (có thay đổi), `+` (đã stage)

**Cấu hình lại bất kỳ lúc nào:**
```bash
p10k configure
```

## 6. Workflow cho người phát triển

### 6.1. Tích hợp Git

Với plugin Git của Oh My Zsh và theme Powerlevel10k:

**Alias Git (từ plugin `git`):**
```bash
# Common commands
gst       # git status
ga .      # git add .
gcmsg     # git commit -m "message"
gp        # git push
gl        # git pull
gco       # git checkout
gcb       # git checkout -b (new branch)
glog      # git log --oneline --graph
```

**Trạng thái Git trong prompt:**
```bash
# Your prompt shows:
~/my-repo (main ✓)      # Clean repo
~/my-repo (main !)      # Uncommitted changes
~/my-repo (feat/new-feature +) # Staged changes
```

**Xem tất cả alias Git:**
```bash
alias | grep git
```

### 6.2. Workflow Docker

Bật plugin `docker` và `docker-compose`:

```bash
# ~/.zshrc
plugins=(... docker docker-compose)
```

**Alias Docker:**
```bash
# Common commands
dps       # docker ps
di        # docker images
dex       # docker exec -it
dstop     # docker stop
drm       # docker rm
drmf      # docker rm -f
```

**Tự động hoàn thiện Docker:**
```bash
docker <TAB>              # Shows all commands
docker run <TAB>          # Shows images
docker exec <TAB>         # Shows running containers
```

## 7. Đồng bộ cấu hình Zsh giữa các máy

Một kho dotfiles có thể giữ cấu hình Zsh giống nhau trên laptop và cụm HPC. Vì các cụm HPC thường mount thư mục home qua NFS, cấu hình sau đó cũng có sẵn trên các compute node.

### 7.1. Tạo kho dotfiles

**Trên laptop:**

```bash
# Create dotfiles directory
mkdir -p ~/dotfiles
cd ~/dotfiles

# Initialize Git
git init

# Copy your Zsh config
cp ~/.zshrc zshrc

# Add and commit
git add zshrc
git commit -m "Initial commit: Zsh config"

# Create GitHub repo and push
git remote add origin https://github.com/yourusername/dotfiles.git
git branch -M main
git push -u origin main
```

### 7.2. Liên kết cấu hình trên từng máy

**Trên laptop hoặc login node HPC (sau khi clone):**

```bash
# Clone dotfiles
git clone https://github.com/yourusername/dotfiles.git ~/dotfiles

# Create symlink to Zsh config
rm ~/.zshrc  # Backup original if needed
ln -s ~/dotfiles/zshrc ~/.zshrc

# Verify
cat ~/.zshrc | head -5
```

### 7.3. Workflow trên HPC

Hầu hết cụm HPC mount thư mục home qua NFS, nên kho `~/dotfiles` có sẵn trên các compute node mà không cần thiết lập thêm.

```bash
# On HPC login node
git clone https://github.com/yourusername/dotfiles.git ~/dotfiles
ln -s ~/dotfiles/zshrc ~/.zshrc

# Your config is now available on all compute nodes via shared home!
# Launch Zsh on any node:
zsh
```

**Lợi ích cho HPC:**
- một tệp cấu hình cho cả login node và compute node
- không cần cấu hình Zsh riêng trên từng máy
- cập nhật chỉ là một lệnh `git pull` trong `~/dotfiles`

### 7.4. Cập nhật cấu hình trên mọi máy

```bash
# Edit ~/.zshrc on desktop
nano ~/.zshrc

# Commit and push changes
cd ~/dotfiles
git add zshrc
git commit -m "Update: Add new alias"
git push

# On HPC, pull latest config
cd ~/dotfiles
git pull

# Changes take effect in new terminal session
exec zsh
```

## 8. Các bước tiếp theo

Shell giờ đã được cấu hình với Zsh và Oh My Zsh, không cần quyền quản trị, và cùng cấu hình đó dùng được trên laptop, dưới WSL và trên cụm HPC.

**Gợi ý các bước tiếp theo:**
1. **Sao lưu cấu hình** - commit `~/.zshrc` vào một kho dotfiles (mục 7)
2. **Khám phá thêm plugin** - danh mục Oh My Zsh ở https://github.com/ohmyzsh/ohmyzsh/wiki/Plugins
3. **Học các phím tắt Git** - chạy `alias | grep git` để liệt kê alias từ plugin
4. **Dùng cùng cấu hình trên HPC** - clone kho dotfiles trên cụm
